# Starter glossary: software English.
# Technical nouns (Rule 1.5) and technical verbs (Rule 1.12) for: --glossary glossary/software.txt
# The category number after each block name names its technical-noun category.
# One term per line. Plurals are accepted automatically. Other verb forms are listed explicitly.
#
# A glossary term switches off every check on that word. For a word with a non-approved
# verb sense (log, branch, build, job, file, key, service), the checker cannot see a verb use.
# Write the approved verb yourself: log (v) -> RECORD, branch (v) -> DIVIDE, build (v) -> ASSEMBLE.
#
# Not here because the dictionary already approves them: test (n), deploy (v), error, change,
# code (n), function (n), method, type, interface, value, unit, row, container, incident, approval.
# Not here because the general word is non-approved: request, option, fix, process, approve.
# Use the multi-word terms below (merge request, HTTP request) or an approved word.
